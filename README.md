# TaskFlow – Task Management Application

## Overview

TaskFlow is a modern task management web application that helps users create, organize, update, and track their daily tasks efficiently. The application provides a clean and responsive interface with user authentication and task management features.

## Features

### User Authentication & Authorization

* User Registration
* User Login
* Secure Authentication
* Protected Routes

### Task Management

* Create Tasks
* View Tasks
* Update Tasks
* Delete Tasks
* Track Task Status

### Dashboard

* Overview of Tasks
* Task Statistics
* Organized Task Display

### Responsive Design

* Desktop Friendly
* Tablet Friendly
* Mobile Friendly

## Technology Stack

### Frontend

* React.js
* TypeScript
* Vite
* Tailwind CSS

### Package Manager

* Bun

## Installation

### Clone the Repository

git clone https://github.com/Mownaprasath123/task_management_system.git

### Navigate to Project Folder

cd task_management_system

### Install Dependencies

bun install

### Run Development Server

bun run dev

### Open Browser

http://localhost:8080

## Build for Production

bun run build
